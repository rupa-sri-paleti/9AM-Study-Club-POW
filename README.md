# 🤝 Why This Workflow?

This repository uses **both directories and branches**.

- **Directories** keep everyone's work organized after it is merged into `main`.
- **Branches** allow each member to work independently while learning real-world Git collaboration.

This approach helps us stay organized while building practical Git skills that are commonly used in software development.

# 💻 First-Time Setup

Clone the repository.

```bash
git clone <repository-url>
cd 9AM-Study-Club-POW
```

Fetch all branches.

```bash
git fetch origin
```

Switch to your branch.

```bash
git checkout <your-branch>
```

Example:

```bash
git checkout gayathri
```

---

# 📅 Daily Workflow

Pull the latest changes from `main`.

```bash
git pull origin main
```

Work only inside your own directory.

Stage your changes.

```bash
git add .
```

Commit your work.

```bash
git commit -m "Day XX - Topic Name"
```

Push to your branch.

```bash
git push
```

---

# 🔀 Pull Requests

After completing a topic (or at the end of the week):

- Create a Pull Request
- Merge your branch into `main`

---

# ✅ Rules

- Work only on your own branch.
- Work only inside your own directory.
- Do not modify another member's directory.
- Do not push directly to `main`.
- Write meaningful commit messages.
- Commit regularly to maintain consistency.
